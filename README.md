# tlf2cosb - TLF to Contest Online Score Board converter

Convert data from [**TLF**](https://github.com/tlf/tlf) contest logger
into a format suitable for [**Contest Online Score Board**](https://contestonlinescore.com) (COSB)
submission and live score reporting.

## Features

- Reads log file generated by TLF extracting scoring and multiplier data
- Periodically sends score information to Contest Online Score Board
- Supports the ~500 contests listed on COSB
- Configurable through INI files
- Lightweight Python implementation
